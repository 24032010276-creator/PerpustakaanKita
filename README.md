# Perpustakaan Kita (Static Demo)

Situs demo frontend statis untuk aplikasi Perpustakaan UNESA.

## Cara publikasi ke GitHub Pages (singkat)
1. Ubah file utama menjadi `index.html` (sudah saya buat).
2. Inisialisasi git, commit, lalu push ke repo GitHub (contoh):

```bash
cd /d d:\wawa
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

3. Di GitHub → Settings → Pages → pilih Branch `main` dan folder `/(root)` → Save.
4. URL: `https://<username>.github.io/<repo>/`

Jika Anda mau, saya bisa membuat repo GitHub untuk Anda (menggunakan `gh` CLI) dan / atau push otomatis — beri izin konfirmasi dulu.
